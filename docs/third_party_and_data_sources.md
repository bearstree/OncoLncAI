# Third-party software and data sources

OncoLncAI source code is licensed under Apache-2.0. Dependencies retain their
own licenses; review the locked dependency set before redistribution.

Biomedical records and datasets are not relicensed by this repository:

- **NCI Genomic Data Commons (GDC):** TCGA project, clinical, and biospecimen
  metadata. Users must follow GDC access and data-use policies.
- **UCSC Xena:** hosted TCGA expression matrices and associated metadata. Each
  artifact retains its hub URL, dataset identifier, and checksum/version.
- **NCBI GEO:** dataset discovery and validation metadata. GEO accession and
  source provenance are preserved.
- **PubMed:** citation metadata and abstracts retrieved through NCBI
  E-utilities. PMIDs remain attached to extracted evidence.

The application reports computed research results, not redistributed ownership
of the underlying records. Restricted or controlled-access data are outside the
public demo scope.
